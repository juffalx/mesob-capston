# 🍽️ Mesob — React Capstone Project

> **Still Learning. Still Building. Still Practicing.**

Mesob is my **React Capstone Project**, developed as part of my **CodeOps Full Stack Software Development** journey at **IBT College of Canada**.

The purpose of this project was to take a frontend product idea and turn it into a functional React application while bringing together the React concepts I have been learning throughout the program.

Rather than focusing only on the visual side, I wanted to understand how the application works behind the UI — including **state management, routing, forms, authentication, reusable components, and application logic**.

---

## 📌 About the Project

**Mesob** is a food-related web application where users can browse products, view product information, manage their shopping cart, and interact with different parts of the application.

The project gave me an opportunity to connect individual React concepts I had studied separately and use them together in a complete application.

### 🎯 Main Goals

- Build a functional React application from a frontend product idea
- Practice reusable component development
- Manage shared application state
- Implement client-side routing
- Handle and validate forms
- Practice authentication-related state
- Build responsive interfaces
- Improve debugging and problem-solving skills
- Understand how different React concepts work together

## ✨ Main Features

### 🛒 Shopping Cart

Users can:

- ➕ Add products to the cart
- ➖ Increase or decrease quantities
- 🗑️ Remove products
- 🧾 View cart information
- 🔄 Keep cart state available across the application

### 🔐 Authentication

The application includes authentication-related functionality and manages authentication state through the application store.

### 📝 Forms & Validation

Forms are handled using **React Hook Form**, including:

- Form state management
- Input handling
- Validation
- Error handling

### 🗂️ Global State Management

I used **Zustand** to manage shared application state.

This allows important state such as:

- Cart data
- Authentication state
- Shared application information

to be accessed without unnecessarily passing data through multiple component levels.

### 🧭 Routing

The application uses **React Router** to handle navigation between different pages and sections.

I had to think about questions such as:

- Where should state live?
- Which state should be global?

- How should forms be handled?
- How should validation work?
- How should routes connect different parts of the application?
- How can components remain reusable?
- How do different features work together?

This project helped me move from learning individual React concepts to actually **connecting those concepts inside one application**.
